# Zlet Limits

**Простой и красивый монитор лимитов AI-кодинга для Windows.**

Zlet Limits показывает, сколько лимита осталось у AI coding-провайдеров, когда сбросится каждое quota window и какой сервис сейчас имеет больше доступного ресурса. Без перегруженного интерфейса, похожего на пульт управления электростанцией.

> Status: early development / bootstrap in progress.

## Цель

Сделать компактное Windows-приложение в системном трее, которое отвечает на три простых вопроса:

1. Сколько лимита осталось?
2. Когда сбросится каждый лимит?
3. Какой AI-сервис сейчас имеет больше доступного ресурса?

## MVP

Первая версия ориентирована на четыре основных провайдера:

- OpenAI Codex
- Google Antigravity
- Claude Code
- OpenCode / OpenCode Go

Позже могут быть добавлены OpenRouter и другие провайдеры. Backend implementations из upstream не удаляются только потому, что они не входят в первый публичный UI.

## Принципы продукта

- **Tray-first.** Основная информация доступна в один клик из системного трея.
- **Простой, но не обрезанный UI.** Упрощаем визуальную иерархию, а не полезные данные.
- **Отдельный reset для каждого окна.** Session/5h и weekly всегда имеют собственное время сброса, если провайдер его отдаёт.
- **Русский и английский интерфейс.** Русская локализация является полноценной, а не машинным переводом поверх английского UI.
- **Local-first.** По возможности используются уже существующие локальные CLI-сессии и credentials.
- **Без лишних секретов.** Не требовать API-ключ там, где можно безопасно использовать существующую локальную авторизацию.
- **Понятные ошибки.** Пользователь должен видеть, что именно не работает и что с этим делать.
- **Windows-native feel.** Спокойный современный интерфейс с хорошей типографикой, отступами и масштабированием Windows.

## Планируемый интерфейс

```text
Zlet Limits

Codex
5 часов     72% осталось   Сброс через 2 ч 17 мин
Неделя      48% осталось   Сброс: 14 сен, 03:00

Antigravity
Gemini
  5 часов   84% осталось   Сброс через 1 ч 08 мин
  Неделя    63% осталось   Сброс: 13 сен, 10:00
Claude + GPT
  5 часов   31% осталось   Сброс через 3 ч 41 мин
  Неделя    74% осталось   Сброс: 15 сен, 18:00

Обновлено 12 сек. назад
```

Provider-specific детали не удаляются: они могут быть доступны через раскрытие карточки, detail view или Settings / Advanced.

Дополнительно планируются:

- компактный статус в tray;
- уведомления при достижении порогов лимита;
- режим «Осталось / Использовано»;
- сводка «что закончится первым»;
- рекомендация, какой доступный провайдер сейчас разумнее использовать для большой задачи.

## Технологии

База проекта:

- **Tauri 2** — Windows desktop shell;
- **React + TypeScript** — UI;
- **Rust** — provider/backend layer;
- Windows DPAPI / secure local storage для секретов, когда они действительно нужны.

## Development bootstrap

Первый технический bootstrap основан на фиксированном Win-CodexBar `v0.55.0` / commit `bdf0773f66c60810886037cfe5f160e0a9fa4fe7`.

После клонирования репозитория на Windows:

```powershell
git clone --recurse-submodules https://github.com/iWebCod/zlet-limits.git
cd zlet-limits
.\scripts\bootstrap.ps1
```

Скрипт:

1. проверяет точный upstream commit;
2. отказывается работать с изменённым `vendor/win-codexbar`;
3. создаёт disposable workspace `.work/zlet-limits`;
4. применяет минимальный Zlet rebranding к product metadata;
5. оставляет upstream provider/backend logic нетронутой.

Для запуска generated workspace:

```powershell
cd .\.work\zlet-limits
.\scripts\dev.ps1
```

`vendor/win-codexbar` считается read-only upstream. Подробнее: [docs/UPSTREAM.md](docs/UPSTREAM.md).
